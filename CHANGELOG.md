# Changelog

All notable changes to the Universal GitHub Project Installer are documented here.

## [1.0.0] - 2026-11-15

### Added
- Phase 1: Flutter Desktop foundation and Material Design 3 interface with Dark and Light mode.
- Phase 2: GitHub repository URL validator, metadata fetcher, and Git clone engine.
- Phase 3: Modular Technology Detection Engine for PHP (Laravel, WordPress, Symfony, CodeIgniter), Node.js (Next.js, React, Express, Vue, Nuxt, NestJS, Vite), and Python (Django, FastAPI, Flask, Streamlit).
- Phase 4: Host runtime detection, missing runtime guides, and dependency installation planner.
- Phase 5: Database manager supporting zero-config SQLite, MySQL, MariaDB, Postgres, and MongoDB.
- Phase 6: Multiple Project Management dashboard with search and language filters.
- Phase 7: Local project execution engine with port conflict detection and live streaming logs.
- Phase 8: Public tunnel manager with Cloudflare Tunnel integration and secure URL generation.
- Phase 9: Automated testing center detecting Jest, Vitest, Pytest, PHPUnit, and Pest with HTTP checks.
- Phase 10: Multi-provider AI Development Assistant (Gemini, OpenAI, Anthropic, OpenRouter, Ollama).
- Phase 11 & 16: GitHub Actions release automation for Windows and macOS.
- Phase 12 & 13: Security scanner, encrypted credential vault, and interactive command authorization.
